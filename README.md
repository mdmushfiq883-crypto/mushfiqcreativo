## 6. How to Run Locally

### Option A: Using the Included PowerShell Server (Recommended for Windows)
Open PowerShell in the `seo-portfolio` folder and run:
```powershell
.\serve.ps1
```
Then open your browser to:
[http://localhost:8080/](http://localhost:8080/)

### Option B: Using Python (if installed)
```bash
python -m http.server 8080
```

### Option C: Using Node.js / npx (if installed)
```bash
npx serve .
```

### Option D: Direct Browser Browsing
Double click `index.html` to open directly in any modern browser (Chrome, Edge, Firefox, Safari). All internal links are engineered with relative navigation (`./`, `../`) so all three pages navigate properly without requiring an HTTP server.

## 7. How to Deploy to Production

### 1. Netlify (Drag & Drop or Git)
1. Go to [Netlify](https://www.netlify.com/).
2. Drag and drop the `seo-portfolio` folder directly into the Netlify dashboard.
3. Your website will be live with SSL, global CDN, and automatic clean URL routing.

### 2. Vercel
1. Install Vercel CLI (`npm i -g vercel`) or import via GitHub repository.
2. Run `vercel deploy`.

### 3. GitHub Pages
1. Push the files to a GitHub repository.
2. In Settings → Pages, select the `main` branch root `/` and save.

### 4. Cloudflare Pages
1. Connect your repository to Cloudflare Pages.
2. Set build command to empty and publish directory to `./`.

### 5. Traditional cPanel / Apache / Nginx
1. Upload the contents of `seo-portfolio` into `public_html`.
2. All clean directory URLs (`/on-page-seo/`, `/portfolio/`) will resolve automatically via directory `index.html` files.
